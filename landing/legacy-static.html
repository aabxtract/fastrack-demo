CLI + MCP SERVER

Plain English in.
Workflows out.

Type what you want. FASTRACK parses it, builds a workflow, runs it across ten connected tools — and fixes itself when a step breaks. Your memory stays in a local SQLite file. Your model? Bring any of them.

$ npm install -g fastrack-cli
fastrack — ~/.fastrack

THE PIPELINE

What happens when you press enter.

Every command walks the same path. No configuration, no YAML, no clicking.

01 — PARSE

Sentence → plan

The model reads your intent and extracts the steps, the tools, and the order they run in.

02 — BUILD

Plan → workflow

The plan becomes a named workflow, saved to SQLite on your machine. It survives restarts.

03 — RUN

Workflow → tools

Each step hits a real connector — GitHub, Notion, Slack — with your credentials, from your machine.

04 — FIX

Fail → self-heal

A step fails, the model reads the error and corrects the parameters. Up to three retries, then an honest failure.

05 — IMPROVE

Runs → insight

After every third success it studies your last ten runs and offers an optimization. You apply it or not.

LOCAL MEMORY

Your machine keeps the receipts.

Workflows, context, and every run's history live in one SQLite file. Nothing leaves your machine except the API calls you ask for.

~/.fastrack/fastrack.db · wipe it anytime with fastrack memory clear

ALSO ON BOARD

Three habits it picks up.

REPORTS

Status from everywhere, delivered anywhere

Pulls activity from your connected tools into one formatted report — and ships it to Slack, email, or Notion.

fastrack report --send slack,email

NOTES

Meeting notes become workflows

Paste your notes; it extracts decisions and action items, then offers to build the workflows that execute them.

fastrack note --file standup.md

SCHEDULES

"Every morning at 9am" is real cron

Say it in a sentence and it becomes a recurring job, kept alive by the daemon or the MCP server.

fastrack daemon

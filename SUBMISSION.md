# Submission kit

## Submission blurb (paste into the hackathon form)

FASTRACK is a Node.js CLI + MCP server that turns plain English into working, self-healing workflows. Describe what you want — "every Friday at 4pm send my team a status report" — and FASTRACK parses the intent, builds the workflow from real tool connectors (GitHub, Notion, Linear, Jira, Slack, Discord, Telegram, Airtable, Email, Webhooks), runs it, retries and fixes failed steps on its own, and suggests optimizations after repeat runs. It is model agnostic (Groq, OpenAI, Anthropic, Google, or any OpenAI-compatible endpoint — including a hosted managed relay for users with no provider account), keeps all memory local in SQLite, and exposes every command as MCP tools so coding agents like Claude Code and Cursor can drive it. Built with GLM-5.3 Flash.
